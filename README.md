# Organic Farming Hub - Sustainable Agriculture Website

A comprehensive web application designed to support farmers with organic farming education and real-time assistance.

## 🌱 Project Overview

**Domain:** Web Application | **Languages:** HTML, CSS, JavaScript

This platform provides farmers with essential resources on organic farming practices, regional language support, and instant assistance through an integrated chat system.

## ✨ Key Features

- **Educational Content Hub**: Comprehensive guides on organic farming techniques including composting, crop rotation, pollinator support, and cover crops
- **Multi-Language Support**: Six regional languages (English, Spanish, Hindi, Tamil, Telugu, Marathi) to reach diverse farming communities
- **AI-Powered Chat Assistant**: User-friendly chat interface providing instant answers to organic farming questions
- **Responsive Design**: Mobile-first approach ensuring accessibility on all devices
- **Modern UI/UX**: Clean, intuitive interface with smooth animations and accessible navigation

## 🛠️ Tech Stack

- **HTML5**: Semantic, accessible markup
- **CSS3**: Flexbox/Grid layout, custom properties, responsive design
- **JavaScript (ES6+)**: Interactive features, language switching, chatbot functionality

## 🎯 Usage

1. Clone or download the repository
2. Open `index.html` in any modern web browser
3. Navigate using the top menu or scroll
4. Select your preferred language from the dropdown
5. Get help instantly through the chat interface

## 🔧 Customization

- **Language Additions**: Add new translations in the `translations` object in `script.js`
- **Content Updates**: Modify section content in `index.html`
- **Styling**: Customize colors and spacing in `:root` variables in `styles.css`
- **Chat Responses**: Extend the keyword-response mapping in the `sendMessage()` function

## 🌿 Target Users

- Organic farmers seeking best practices
- Agriculture students and researchers
- Farming cooperatives and NGOs
- Anyone interested in sustainable agriculture
